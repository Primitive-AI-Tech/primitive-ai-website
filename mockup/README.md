## Generation and scope

Images were generated with the built-in Image Generation tool and saved in this repository. This is a local design package; production website source has not been replaced or deployed.

These are visual concepts. Embedded application panels use sample information, and modeled productivity figures are illustrative. Component notes and interaction specifications define exact behavior and numbers; verified claims and real source assets are required when implementing the public website.

The source logo is preserved as `references/prai-logo-original.png`. Production must use the authentic logo asset rather than a generated rendering of its mark.

## Palette decisions

2. Logo-derived indigo/cyan exploration.

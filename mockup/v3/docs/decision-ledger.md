## What changed from V2

- Page navigation replaces the Core Agentic/Use Cases/Customers/How We Work/Company header.
- Broad work examples replace the three-configuration constraint. There is no separate primary Use Cases page in the proposed IA.
- Products and Services have their own proposed destinations. About no longer doubles as the separate-product catalog.
- Custom AI Development returns as a full engineering offer. `/services` no longer redirects to the homepage process.
- The named company path is restored; the generic Applied AI foundations stage is removed.
- NEU is the eighth customer; real customer/partner images are a production requirement.
- `/about` and `/update` replace V2's `/company` and `/updates` canonicals.

## Source and copy boundaries

The generated boards are visual references. Exact identity assets, source classifications and copy in the component guide control implementation. Founder-question wording and editorial card titles are design copy, not new attributed quotations or published posts. The older 2020 founding date, stale beta/coming-soon statements, anonymous customer metrics and unverified marketing counts are not restored with the older source material.

No production migration, deployment or DNS operation occurs in this design step. The prior code refactor remains intact. The recommended Products/Services split is available for review in [review-notes.md](review-notes.md), without reopening directions the owner has already supplied.

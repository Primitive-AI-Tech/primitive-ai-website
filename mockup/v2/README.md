## Files

- `images`: seven selected review boards, generated with the built-in image tool.
- `references`: copies of current implementation captures and the original brand/founder inputs.
- `prompts`: the complete prompt set, including targeted corrections.
- `docs`: approved design basis, descriptions, review notes and provenance.
- `explorations`: superseded first-pass images, excluded from the review gallery.

These are mockups, not new production pages or real product screenshots. Update headlines are editorial design drafts, without invented publication dates. Customer/partner artwork is simplified to names in some boards; implementation uses approved source assets and the exact owner-approved roster.

The running code was refactored separately while preserving the current composition. Homepage replacement, route consolidation and new content await the next implementation phase after this visual review.
